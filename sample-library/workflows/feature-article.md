# Feature article

1. **Research.** Run `research-brief` on the topic and the client's question. The writer confirms the angle.
2. **Interview.** Book the people the brief suggests. Record with their permission.
3. **Clean the transcript.** Run `transcript-clean-up` on each recording.
4. **Draft.** Run `interview-to-draft` with the cleaned transcripts and the confirmed angle.
5. **Check.** The writer checks every item in the draft's "claims that need checking" list against the sources.
6. **Hand off.** The draft goes to the editor with the brief, the transcripts and the checked list.

A person signs off steps 1, 5 and 6. Agents may do steps 3 and 4.
