# New client kickoff

1. **Contract.** Run `contract-summary` on the signed agreement. Share the summary with everyone on the account.
2. **Background.** Run `research-brief` on the client's market, using their own question about it.
3. **Pitch the first piece.** Run `pitch-deck-outline` for the first piece of work. Keep it to five slides.
4. **Kickoff call.** Walk the client through the outline. Write down every change they ask for.
5. **Agree.** Send the revised outline and the dates. Work starts when the client agrees in writing.

A person runs the kickoff call and sends everything the client sees.
