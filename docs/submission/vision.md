Writers, researchers and editors now run their work through AI agents, and the skills those agents follow are becoming the team's real playbook. Today that playbook lives in someone's chat history or a shared doc nobody trusts. GitHub would fix it, but nobody on a content team wants to learn branches and pull requests.

Stylebook is GitHub for those teams. It is a shared, versioned library of a team's skills, tool connections and workflows. Every person and every agent works in their own copy, so dozens of agents can suggest changes at once without touching the library. An editor reads each suggestion marked up on the page like a proof, sees who made it, for whom and why, and publishes the one they want as a new edition. When two suggestions change the same lines, Stylebook says so in words and offers to keep one, keep the other, or have an agent combine them.

Connecting Claude or Cursor is one address and a sign-in, no keys or config files. And because it is plain Git underneath, the whole workspace downloads as a folder with its full history. The team is never locked in.
